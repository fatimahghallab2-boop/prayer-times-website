# 🌙 Prayer Times Website

A responsive prayer times web website built with HTML, CSS, and JavaScript.

## 🌟 About the Project

Prayer Times is a dynamic web application created as a practice project to improve my front-end development skills and apply what I have learned in JavaScript. The website allows users to view accurate, real-time prayer schedules and Hijri dates for major cities in Saudi Arabia, featuring a smart algorithm to automatically highlight the upcoming prayer.

## ✨ Features

- **Dynamic City Selection:** Switch between major Saudi cities (Riyadh, Makkah, Jeddah, Dammam) with instant updates.
- **Real-Time API Integration:** Fetches accurate prayer timings and Hijri calendar data using Axios and the Aladhan API.
- **Next Prayer Highlight:** Automatically calculates the current time and highlights the upcoming prayer using a time-to-minutes algorithm.
- **Hijri Date Display:** Shows the current Islamic Hijri date, month, and weekday in Arabic.
- **Modern UI/UX:** Clean design styled with custom CSS, Google Fonts (Tajawal), and FontAwesome icons.

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6+)
- Axios (HTTP Requests)
- Font Awesome
- Google Fonts (Tajawal)
- Aladhan API

## 📚 What I Learned

Through this project, I practiced:
- Fetching and handling data from an external API using Axios.
- Working with dates and converting time strings into minutes for comparison logic.
- Using DOM manipulation to dynamically update webpage content and styles.
- Creating modular JavaScript functions.
- Integrating third-party icon libraries and styling responsive layouts from scratch.
